# Syntax Masters

A Java Swing quiz game that tests programming, math, and general knowledge across 5 levels.

## Tech Stack
- Java 23
- Swing / NetBeans GUI Builder
- Maven

## How to Run
1. Clone the repo
2. Open in NetBeans (or run `mvn compile exec:java`)
3. Requires Maven dependencies (AbsoluteLayout, lwjgl3-awt) — see pom.xml

## Features
- Java & Python quiz tracks
- 5 difficulty levels with animated transitions
- Background music & sound effects with toggle settings
- Accuracy tracking & earned titles
